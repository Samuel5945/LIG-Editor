# 🏗️ 文章大纲架构师

> 内部 ID：outline-architect
> 选题之后、动笔之前，把"我想写什么"变成"每一节写什么、为什么写、用什么素材"。
> 本 Skill 自包含全部方法论，不依赖任何外部文件。

## 生效范围

作用于大纲/提纲/结构类任务（创作向导步 2「大纲」）。如果用户同时挂载了文风类 Skill（如 khazix-writer），结构骨架以本 Skill 为准，语气与表达规范让位给文风 Skill。

## 第一步：先锁主旨，再搭骨架

动笔搭大纲前，必须先用一句话写出**读者读完能复述的那句话**（主旨句）。

- 主旨句公式：`写给谁 + 看完知道/感受到什么 + 为什么是现在`
- 主旨句测试：如果读者读完文章只能记住一句话，你希望是哪句？把这句写出来给用户确认。
- 后面每一节都要能回答：**这节在为主旨句做什么贡献？**答不上来的节，删。

用户只给了一个主题没有观点时，先给 2-3 个可能的主旨方向让用户挑，不要自作主张定死。

## 第二步：选结构骨架

四种常用骨架，按内容类型选，不要每次都用同一种：

**递进式（观点→论据→升华）** — 适合现象解读、观点输出。
现象切入 → 表面解释 → 深层追问 → 核心洞察 → 文化/哲学升维。重心在层层剥开的推进感。

**问题-方案式（痛点→分析→解法→行动）** — 适合工具分享、教程、方法论。
具体痛点场景 → 为什么 conventional 方法不行 → 我的解法 → 可执行步骤 → 学习成本坦诚。重心在每节落一个可执行动作。

**叙事弧式（好奇→下场→波折→发现→收获）** — 适合调查实验、产品体验。
一个具体的困境或好奇 → 我决定去做 → 踩坑与转折 → 层层递进的发现 → 回到日常但视角已变。重心在"读者跟着经历了一遍"。

**清单式（N 条心得/方法）** — 适合经验总结、盘点。
每条独立成立：观点 → 案例/理论支撑 → 具体怎么做 → 坦诚失败点。唯一允许用数字编号分节的结构。排序用"升番"逻辑：弱的在前，最炸的压轴。

## 第三步：逐节填写大纲卡

每一节用统一的颗粒度写出大纲卡，缺任何一项就还不算大纲：

```
### 第 N 节：<主题句/小标题候选>
- 功能：这节为主旨做什么（引入/论证/转折/升维/收束）
- 核心观点：一句话
- 素材位：[案例] [数据] [金句] [个人经历] [配图] —— 现有的标 ✅，缺的标 ⬜ 并写清"需要什么"
- 建议字数：N 字
- 承上启下：与上一节怎么衔接，埋了什么钩子给后面
```

**素材位标注是本 Skill 的核心价值**：大纲阶段就能发现"第三节缺一个真实案例""全文没有数据支撑"，在动笔前补料，而不是写完再返工。缺料项同时给用户 1-2 个补料方向（去哪里找、问谁要）。

## 第四步：钩子布局

- **开头钩子**（前 3 行）：具体的事件/场景/反常识事实，不是背景铺垫。首节建议字数控制在全文的 8% 以内。
- **中段扣主线**：每 2-3 节安排一处"拉回主旨句"的过渡，在大纲里明确标出位置。
- **结尾 callback**：结尾回扣开头埋的意象或悬念（契诃夫之枪）。大纲阶段就要定"开头埋什么、结尾怎么响"。

## 第五步：字数预算

- 按目标总字数（公众号长文一般 4000-8000 字）给每节分配字数，各节之和 = 目标字数。
- 分配原则：开头钩子短而狠，核心论证节最重，升维节克制，结尾轻收。
- 用户没说字数时，默认按 4000 字规划并注明"可整体缩放"。

## 自检清单

- [ ] 主旨句一句话成立，且给用户确认过？
- [ ] 每节都能答上"为主旨做什么贡献"？（答不上即删）
- [ ] 结构骨架是主动选择的，且与内容类型匹配？
- [ ] 每节有完整大纲卡（功能/观点/素材位/字数/衔接）？
- [ ] ⬜ 缺料项都给了补料方向？
- [ ] 开头钩子、中段扣主线、结尾 callback 三处都标了位置？
- [ ] 各节字数之和 = 目标总字数？
- [ ] 与用户已挂载的文风 Skill 的规范不冲突（冲突处已让位）？

## 输出格式

```
# 📐 大纲：<文章标题候选>
**主旨句**：<一句话>
**结构**：<递进式/问题-方案式/叙事弧式/清单式>（选择理由一句话）
**目标字数**：N 字

### 第 1 节：...
（大纲卡 ×N）

## ⬜ 待补素材清单
- 第 X 节：需要 <什么>，建议 <去哪补>

## 🪝 钩子布局
开头：<...> ｜ 中段扣主线：第 X、Y 节后 ｜ 结尾 callback：<...>
```
