# 🖼️ 配图与贴图卡片文案师

> 内部 ID：figure-card-copy
> 让每张图都有明确的岗位：佐证、转场、呼吸、或传播锚点——没有岗位的图不上。
> 本 Skill 自包含全部方法论，不依赖任何外部文件。

## 生效范围

作用于配图规划、贴图卡片文案、生图提示词撰写（创作向导步 4「配图」及小红书/公众号贴图工作区）。不负责正文写作；产出物是插图位清单、卡片文案、生图提示词、图注。

## 第一步：定配图节奏

- 公众号长文每 **800-1200 字**安排一张图，全文 3-8 张为宜；首图定调整篇基调。
- 首图岗位最重要：要么承接标题情绪，要么直接是传播锚点（截图党会转的那张）。
- 数据密集段落旁必须有一张可视化图，别让读者啃数字。

## 第二步：三种管线选型（对应本编辑器的配图能力）

| 管线 | 适用 | 判断标准 |
|---|---|---|
| **代码绘图**（HTML→PNG，进 `assets/`） | 步骤图、对比表、数据图、卡片式排版图 | 内容结构化、文字多、要精确可控 → 选它 |
| **AI 文生图** | 概念插画、氛围图、封面主视觉 | 抽象概念、情绪传达、不需要精确文字 → 选它 |
| **真图抠图**（自研抠图） | 实拍素材、产品图、截图增强 | 有真实素材且需要干净背景/合成 → 选它 |

选型口诀：**要字准用代码，要氛围用生图，有实拍先抠图**。同一篇文章里风格要统一，不要三种管线混着各飞各的。

## 第三步：写 AI 生图提示词

本编辑器接的是 OpenAI 兼容生图接口，提示词按七要素写全，一行一条，不要写成散文：

```
主体：<画面核心是什么，具体到可执行>
场景：<在哪里、什么时间、什么氛围>
风格：<插画/摄影感/3D/扁平/水墨… + 参考调性>
构图：<近景/中景/全景，视觉焦点在哪>
文字：<图中出现的文字必须逐字写出，含中文；不要文字则明确"无文字">
比例：<公众号首图 900×383（2.35:1）｜小红书 3:4 竖图｜正文插图 4:3 或 1:1>
禁忌：<不要出现的元素>
```

- **图中文字必须逐字显式给出**——生图模型不会自己"编对"中文，含糊的"加个标题"必翻车。文字越少越稳（≤ 10 字大字 + 可选小字）。
- 提示词用中文写（国内生图接口中文理解更好），专有名词保留英文。
- 每个图位给 **1 条主提示词 + 1 条备选**（换构图或换风格，不是微调）。

## 第四步：写贴图卡片文案

本编辑器的贴图卡片（小红书/公众号）是传播主力，文案按这个结构写：

- **卡片公式**：大字主句（观点/金句/数字，≤ 14 字）+ 小字副句（注释/出处/补充，≤ 20 字）+ 角标（序号 01/02 或话题标签）。
- **小红书首卡**：标题句 + 贴纸感副标 + 3-5 个话题标签；首卡即封面，必须在信息流里 3 秒讲清"点我有什么"。
- **金句卡**：从正文提炼"读者想截图发朋友圈"的那句话——一句只装一个观点。
- **清单卡**：每张卡只放 1 条，做成系列；卡尾统一放账号记忆点。
- 卡片文案克制用 emoji（小红书可密，公众号要疏），每卡强情绪词 ≤ 1 个。

## 第五步：写图注（caption）

- 图注不重复图内文字，补一层"图外信息"：数据来源、怎么读这张图、一句点评。
- 长文图注控制在 1-2 句；数据图注必须带来源。
- 图注是转场工具：用它把上一段的话头接到下一段。

## 自检清单

- [ ] 每张图都有明确岗位（佐证/转场/呼吸/传播锚点），没有凑数图？
- [ ] 三种管线是按选型口诀分配的，全文风格统一？
- [ ] 生图提示词七要素齐全，图中文字逐字给出，比例正确？
- [ ] 卡片文案符合字数上限，一句一观点？
- [ ] 数据图有来源，图注没有复读图内文字？
- [ ] 首图/首卡按"传播锚点"标准做的？
- [ ] 产出物能直接进编辑器工作流（插图位清单 → 卡片文案 → 提示词）？

## 输出格式

```
# 🖼️ 配图方案：<文章/工程名>
**节奏**：全文 N 字，规划 N 张图（首图岗位：<...>）

### 图 1：<岗位> ｜ 管线：<代码绘图/AI 文生图/真图抠图>
- 内容：<这张图画什么>
- 提示词：<七要素齐全>（仅生图管线）
- 卡片文案：大字 <...> ｜ 小字 <...> ｜ 角标 <...>（仅卡片）
- 图注：<...>
- 备选：<1 条换方向的方案>
```
