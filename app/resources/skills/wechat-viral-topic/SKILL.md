# 🔥 10万+爆款选题炼金炉

> 内部 ID：wechat-viral-topic
> 把热点原料丢进炉子，炼出能炸出 10万+ 阅读的选题、标题与全形态创作方案。
> 本 Skill 自包含全部方法论（心法、打分卡、风险清单、形态库、输出模板），不依赖任何外部文件。

## 生效范围

本 Skill 是选题方法论，不是文风类 Skill。挂载后优先作用于：脑暴选题、评估素材、起标题、定切入角度。用户进入正文写作/润色阶段时，只保留「标题公式」与「传播锚点」意识，其余让位给写作类 Skill。

## When to use

立刻召唤【10万+爆款选题炼金炉】的信号词：
- "帮我想个朋友圈/公众号/小红书选题"
- "起 5 个爆款标题 / 标题不够吸引人 / 帮我改标题"
- "这个热点怎么做选题 / 怎么蹭"
- "短视频脚本 / 视频号选题 / 抖音选题"
- "漫画选题 / 4 格漫画 / 公众号头图漫画"
- "公众号长文方案 / 文章角度"
- "H5 传播海报标题 / 转发文案 / H5 选题方向"
- "小游戏选题 / 互动玩法选题"
- 用户给一段素材/新闻/产品介绍，问"怎么写才有人转/做什么内容好"

NOT for：写完整的视频成片/最终成稿（本 skill 输出方案+标题+锚点+提纲，而非长文成稿）。

## Core model — 爆款四基因 + 12 条心法 + 6 大形态

任何选题要爆，先过「12 条策划心法」筛（红线/黄线），再命中「四基因」中的至少 2 条，最后映射到 6 大内容形态中的 1+ 种。

### 四基因（选题的爆发力来源，至少命中 2 条才算候选）

1. **情绪钩子（Emotion）** — 愤怒、共鸣、焦虑、惊讶、治愈、爽感。判断：读者看完第一反应是想转发发泄，还是想@朋友说"你看"？一个选题只装 1 个主情绪，多了互相稀释。
2. **信息差（Info-gap）** — 「我知道你不知道」「行业内幕」「反常识」。判断：把选题讲给目标读者听，他会说"哦"还是"真的假的？"。信息差必须是真的，编造的"内幕"是红线。
3. **身份标签（Identity）** — 让读者觉得「这就是我」「替我说出口」。判断：能不能用一句话圈出人群（"刚毕业的打工人""二胎妈妈"），并且这个人正在为这件事憋屈/得意/纠结。
4. **行动触发（Action）** — 实用工具、清单、立刻能用、可复制。判断：读者看完今天就能做一件具体的事吗？"收藏=学会"的错觉越强，转发收藏率越高。

### 12 条心法（策划筛子，红线命中直接毙掉原料）

红线（❌ 命中即弃）：
- ⑩ **立场安全**：不站队、不带节奏、不消费灾难和悲剧。热点再大，立场错了就是事故。
- ⑪ **信息源可信**：信源可追溯到权威渠道（官方通报、论文、当事人一手信源）。"网传""据说"必须标注或替换。
- ⑫ **合规可上线**：广告法违禁词、行业监管（医疗/金融/教育）、平台规则（诱导分享）任一命中，先改合规再谈爆。

黄线（⚠️ 需要补救才能过）：
- ① **用户思维优先**：讲"读者关心什么"，不是"我想说什么"。补救：把主语从产品/自己换成读者。
- ② **热点热度足够**：过气热点不做。补救：换角度做"复盘""反转""后续"，或放弃。
- ③ **传播点明确**：一句话说清"读者为什么转"。说不出 = 没有传播点。
- ④ **可互动可视化**：能被截图、投票、测试、对比。纯文字观点优先改造成可视化载体。
- ⑤ **叙事张力足**：有冲突、有悬念、有反转。平铺直叙的新闻通稿不是选题。
- ⑥ **化繁为简**：一个选题只讲一件事。三件事挤一个标题 = 零件事。
- ⑦ **体验一致性**：标题承诺什么，正文就要给什么。标题党透支信任。
- ⑧ **参与门槛低**：读者 3 秒能看懂、10 秒能参与。门槛每高一格，流失一半人。
- ⑨ **声音加成**：选题适合配语音/视频/音乐表达吗？不适合就别硬做视频形态。

### 6 大内容形态（每个候选选题最终要落到 1+ 种形态）

① **文章标题** ② **文章角度** ③ **公众号长文** ④ **短视频脚本** ⑤ **漫画/插画** ⑥ **H5/小游戏**

多形态联动时间矩阵（"一个热点吃三轮"）：
- **T0（热点爆发 24h 内）**：快评短内容、标题借势、朋友圈/小红书轻内容——抢的是时效
- **T+24~48h**：公众号深度长文、复盘分析——抢的是信息差和角度
- **T+48~72h**：漫画/盘点/互动 H5、反常识角度二创——抢的是情绪沉淀和传播长尾

## 8 维打分卡（每个候选选题必填，总分 ≥ 30/40 才进入输出）

| 维度 | 1 分锚点 | 5 分锚点 |
|---|---|---|
| 情绪 | 读者无感 | 当场想转发发泄/落泪/拍案 |
| 传播 | 只对小圈层有意义 | 跨圈层都愿意转，且转的时候有面子 |
| 独家 | 到处都是同款 | 独家信源/独家角度/独家体验 |
| 身份 | 圈不出具体人群 | 一句话就能让目标读者对号入座 |
| 时效 | 常青话题（可缓存） | 正在爆发期，24h 内发最优 |
| 传播锚点 | 没有可截图传播的页面/帧 | 有一页/一帧/一卡片，截图本身就是作品 |
| 可视化 | 纯文字才能讲清 | 天然适合图/表/对比/分镜 |
| 门槛 | 需要背景知识才懂 | 3 秒看懂，零门槛参与 |

用法：对每个候选选题逐维打分并写出一句理由；总分 < 30 直接淘汰，不心疼。

## Steps（流水线必须按序执行，不许跳步）

### 1. 吸取原料
让用户提供 3 选 1 的输入：① 一段新闻/热点；② 一个产品/项目；③ 一个个人经历/观点。
默认按"全平台、多形态"出方案；用户指定平台/形态则按指定。

### 2. 【必经步骤】12 条心法筛
**在生成任何选题前**，对原料先过一遍上方「12 条心法」。红线命中直接告知用户该原料不适合做爆款选题，建议替代方向。

### 3. 基因匹配
从上方「四基因」中挑出 2-3 条最适合该原料的，写明为什么。

### 4. 生成 3 个候选选题
每个选题用一句话写清「冲突点 + 受众 + 利益」+ **传播锚点**（截图即传播的那一页/那一帧）。

### 5. 12 条心法逐条亮灯
对原料逐条标记 ✅ / ⚠️ / ❌（在原料层做即可，无需每个选题重复打）。

### 6. 8 维打分
用上方「8 维打分卡」逐选题打分（每项 1-5 分，**总分 ≥ 30 才进入下一步**）。低分直接淘汰。

### 7. 【Top 3 优先输出】
**先把 8 维打分排名前 3 的选题作为「Top 3 最推荐方案」聚焦输出**——含基因、锚点、打分、最佳形态、5 条标题、A/B 建议。这是给决策者看的"先选这个就对了"。

### 8. 【全形态参考方案】
基于 Top 3 选题，**横向拆解 6 大形态**，每个形态给一份完整可执行方案：

- **① 文章标题方向**：5 条不同角度的标题，标注公式+平台
- **② 文章角度方向**：3-5 个差异化切入角度（个人经历/反共识/数据/历史/冷知识）
- **③ 公众号长文方案**：选 1 个最适合长文的选题 → 钩子段+目录提纲+金句海报+200 字钩子段范文
- **④ 短视频脚本**：选 1 个最适合视频的选题 → 镜次表（时长+画面+文案+字幕音效）
- **⑤ 漫画/插画方案**：选 1 个最适合漫画的选题 → 4-9 格分镜脚本+主视觉锚点
- **⑥ H5/小游戏方案**：选 1 个最适合互动的选题 → 玩法类型+3 步主流程+首屏文案+结果页

> **每种形态选用哪个 Top 选题，要明确写出"为什么选这条"的理由（1 句话）。**

### 9. 风险自检
对照下方「风险自检清单」自动过滤敏感雷区，发现风险给出替代版本。

### 10. 多形态联动建议
按上方「多形态联动时间矩阵」给"一个热点吃三轮"的时间排期建议。

### 11. 输出格式
使用下方「输出模板（v3）」的结构化格式（含 Top 3 + 全形态参考）。

## 风险自检清单（发布前逐条过）

- **广告法雷区**：「最」「第一」「绝对」「国家级」「顶级」「治愈」「根治」「100%」「零风险」——出现即改写
- **行业敏感**：医疗（诊断/疗效承诺）、金融（收益承诺/荐股）、教育（提分承诺）、政务（站队）——只做科普不做断言
- **平台红线**：诱导分享（"转发解锁""分享后可见"）、外链导流、夸大标题党（正文兑现不了标题）
- **人身与隐私**：未经证实的对具体个人的指控、当事人可识别信息、未成年人隐私
- **版权**：引用图片/字体/段落需有授权或合规来源；转载标注出处
- **信源**：数据必须给出来源；"网传"内容要么核实要么明示不确定性

发现风险的处理方式：给出**替代版本**（改写后的合规表达），而不是简单删掉。

## Pitfalls — 这些坑必须避开

- ❌ **只给 H5 方案**：v3 强制要求覆盖 6 种形态，不能偏科。
- ❌ **跳过 12 条心法直接生成**：垃圾进去就是垃圾出来。
- ❌ **没有「截图锚点」的选题**：再好的故事没有结果页/海报锚点都不算合格选题。
- ❌ **多焦点抢注意**：一个选题塞 3 个观点 = 没观点。
- ❌ **标题党≠爆款**：纯震惊体已经审美疲劳。
- ❌ **不要堆砌情绪词**：一个标题最多 1 个强情绪词。
- ❌ **数字要"奇""具体"**：「7 个」比「5 个」更勾人。
- ❌ **避免内部黑话**：B 端术语在 C 端秒划走（"赋能""抓手""闭环"）。
- ❌ **平台错配**：小红书要 emoji，朋友圈要克制，视频号要前 3 秒钩子。
- ❌ **绝对化用词**：「最」「第一」「绝对」是广告法雷区。
- ❌ **站队/带节奏**：原则 ⑩ 是产品红线。
- ❌ **诱导分享**：「分享解锁」会被微信封链接。

## Verification — 输出前自检清单

回答用户前，**必须**逐条检查：

- [ ] 12 条心法每条都明确标了 ✅/⚠️/❌？
- [ ] **Top 3 推荐方案**是否在最前面突出展示？
- [ ] **全形态参考方案是否覆盖 ≥4 种形态**（标题/角度/长文/短视频/漫画/H5）？
- [ ] 每个选题写出了「传播锚点」（截图即传播的那一帧）？
- [ ] 8 维打分卡填了，总分 ≥ 30？
- [ ] 公众号长文方案给了钩子段范文+目录提纲+金句海报？
- [ ] 短视频脚本给了镜次表（含时长/画面/文案/字幕）？
- [ ] 漫画方案给了分格脚本（含表情/对白/彩蛋）？
- [ ] H5 方案给了 3 步主流程+首屏文案+结果页？
- [ ] 标题至少使用了 4 种不同公式？
- [ ] 标题字数：朋友圈 ≤ 22 / 小红书 ≤ 20 / 公众号 ≤ 28 / 视频号 ≤ 22 / H5 海报 ≤ 14？
- [ ] 信息源可追溯到权威渠道（原则 ⑪）？
- [ ] 风险检查：敏感词、绝对化、夸大、立场？
- [ ] 多形态联动建议（24h-72h 时间矩阵）？

## 自我演化

每次用完本 skill，把学到的沉淀下来（写进用户的选题库/复盘笔记，供下次调用）：
- 用户反馈哪条标题/形态真的转化高 → 提炼公式，在后续输出中提高该公式权重
- 出现新的平台规则/敏感词 → 在「风险自检清单」基础上追加条目
- 用户行业有特殊语境（金融/母婴/游戏/政务/教育） → 输出时按行业调整黄线尺度与案例
- 12 条心法发现新边界案例 → 输出时明确指出并给出当次的判断依据
- 出现新的内容形态（如直播/播客/虚拟人） → 按四基因+心法框架现场推导该形态方案
