# 独立创作向导（Creation Wizard）设计规格

- 日期：2026-09-28
- 状态：设计定稿，待实现
- 对应 PRD：§11.3 第 1 条（三期候选首位）。实现交付时回写 PRD：§7 新增向导节、§11.2「向导式新手流程」转 ✅、§11.3 第 1 条移出候选（滚动补记，不升版本号）。
- 设计过程：visual companion 线框确认（布局=顶部横向步进器；配图步=行式批量清单），mockup 存 `.superpowers/brainstorm/`（已 gitignore）。

## 1. 背景与目标

现状的创作链路「脑暴选题 → 成文 → 配图 → 标题封面 → 审阅 → 导出」已由脑暴面板 + 收尾三步清单 + 页签跳转串通，但存在结构性断点：

1. **多页签手工接力**：中栏正文/标题封面与右栏脑暴/审阅来回横跳，唯一串联物是脑暴 done 阶段的三步清单——看完即消失，无持久进度跟踪；
2. **配图逐张串行**：正文占位无总览，每张图完整走一遍弹窗流程；
3. **进度无事实源**：做到哪一步全凭记忆。

目标：把这六段散点收拢为**一个带事实推导进度的单一路径工作台**，新手获得引导路径，老手获得进度跟踪器——日常每篇创作都走它。

## 2. 已确认的产品决策

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 定位 | 日常主力界面：每篇创作都走它，步骤可跳可回，新手文案渐进披露 |
| 2 | 步骤范围 | PRD 黄金路径全条：选题→大纲→成文→配图→标题封面→审阅→导出。导出即终点；公众号直推/多平台从导出步进；排期不进（跨工程，归日历） |
| 3 | 完成判定 | 事实推导（由工程现实现算），无手工打卡、无持久化向导状态 |
| 4 | 配图步 | 行式批量清单（n/m 进度 + 已插图缩略图条），处理复用现有 FigureDialog 三管线 |
| 5 | 形态 | 方案 A：中栏步进器工作台，分步嵌入既有面板；右栏瘦身为只剩「对话」；脑暴创作/审阅页签退役 |
| 6 | 布局 | 顶部横向步进器（原中栏工具条位置），工作面整幅铺开 |

## 3. 信息架构

### 3.1 中栏

页签条变为 `[🧭 创作] [💡 选题看板] [📅 日历]`。「正文」「标题/封面」页签删除，内容成为向导步骤工作面（组件复用，只是换位置）；选题看板/日历保留为跨工程页签。

向导 = 新组件 `CreationWizard`：顶部横向步进器（7 步，显示每步完成态）+ 下方当前步工作面。步骤即导航：自由点击切换、可跳可回；流式成文期间切步不打断。

| 步骤 | 工作面 | 来源 |
|---|---|---|
| 1 选题 | 投喂素材 / 联网开关 / 补充要求 / 选题卡（入库、生成大纲） | 从 BrainstormPanel 拆出 `BrainstormIdeas` |
| 2 大纲 | 大纲可编辑 + 工程名 + 立项出口（公众号文章 / 贴图 / 写入当前工程） | 从 BrainstormPanel 拆出 `OutlineStep` |
| 3 成文 | `ArticleEditor` 原样嵌入；排版优化/排版导入/转贴图按钮收进步 3 步骤工具条（导出归步 7 专步，不设重复入口） | 现有组件搬家 |
| 4 配图 | 新组件 `FigureChecklist`（见 §5.4） | 新写，管线零改动 |
| 5 标题封面 | `TitleCoverPanel` 原样嵌入 | 现有组件搬家 |
| 6 审阅 | `ReviewPanel` 嵌入（贴图工程换 `CardsReviewPanel`） | 现有组件搬家 |
| 7 导出 | ExportDialog 的弹窗体拆为 `ExportPanel` 内联；ExportDialog 壳保留（其他弹窗入口复用） | 拆分复用 |

### 3.2 右栏

只剩「对话」页签（ChatPanel）。「脑暴创作」「审阅」页签与按钮删除；「三面板常驻挂载保流式」的逻辑随之简化为单面板。Skill 挂载下拉保留在右栏头部、作用范围改为对话本身；向导各 AI 步骤沿用现有「按任务类型自动推荐挂载」机制（脑暴→选题类、生成→风格类）。

### 3.3 深链重接（全量）

| 入口 | 去向 |
|---|---|
| 左栏选题库「生成大纲」 | 向导步 2（带 seed） |
| 选题看板 / 日历卡片「生成大纲」 | 向导步 2（带 seed） |
| 对话面板「去脑暴」按钮 | 向导步 1 |
| 工作树点开工程 / 打开工程 | 向导第一个未完成步 |
| .md 文件关联直开 | 向导步 3 |
| FigureDialog 触发（正文占位卡 / 配图步清单） | 同一弹窗，状态仍在 App（figRequest），不变 |

### 3.4 未立项态

步 1-2 无需工程（与现状脑暴面板一致）。步 3-7 在未开工程时步骤可点击，工作面显示引导卡（「立项或打开工程后解锁此步」），不显示空面板。

## 4. 组件拆分

**新组件**：
- `CreationWizard`（中栏壳）：持有原 BrainstormPanel 阶段机（`input→brainstorming→outlining→outline→writing→done` 中前五个有效阶段，done 由步进器取代）与流式任务状态；渲染步进器 + 按 `activeStep` 切换工作面。流式状态在壳层，切步不卸载任务。
- `BrainstormIdeas`（步 1）：原 BrainstormPanel 的输入/脑暴/选题卡部分，纯搬家。
- `OutlineStep`（步 2）：原大纲编辑 + 工程名 + 立项出口，纯搬家；立项动作上报壳层（切步 3 + 流式）。
- `FigureChecklist`（步 4）：行式批量清单。
- `ExportPanel`（步 7）：ExportDialog 弹窗体抽出，弹窗与内联双用。

**删除**：`BrainstormPanel.tsx`（拆分后删除文件）、右栏 create/review 页签按钮、中栏正文/标题封面页签按钮、脑暴 done 三步清单（`StepRow` 随文件删除）。

**纪律**：BrainstormPanel 拆分「纯搬家不改行为」——阶段机阶段名、提示词、回调签名不变，出问题好回退。

## 5. 进度推导与数据流

### 5.1 完成判定（事实推导，渲染现算）

| 步骤 | 完成判定 | 事实来源 |
|---|---|---|
| 1 选题 | 产出过大纲（会话内）或已立项 | 壳层阶段态 / current 存在 |
| 2 大纲 | 已立项（工程存在即完成） | current 工程 |
| 3 成文 | 正文非空；贴图工程=卡片已生成 | `article.md` / `cards.json` |
| 4 配图 | 正文无 fig-suggest 残留（占位被替换**或删除**均算已处理；最终插几张图由用户决定） | 编辑器文档现算 |
| 5 标题封面 | `meta.cover.main` 存在 | meta |
| 6 审阅 | `review.md` 存在且非空（贴图=`cards-review.md`） | 工程文件 |
| 7 导出 | `meta.lastExportAt` 存在 | meta（**新增字段**） |

推导收敛为 shared 纯函数 `deriveWizardSteps(facts): WizardStepStatus[]`，全量单测。步骤状态零持久化——Agent 改文件、外部编辑、多窗口都如实反映，与选题看板「状态由工程推导」哲学同源。

**meta.lastExportAt**：导出/复制富文本/推送成功时写入 ISO 时间串。**`readMeta` 白名单同步透传**（PRD §14 点名的回归高发处，实现时显式核对）。

### 5.2 默认落点

打开/切换工程时落在第一个未完成步（全完成落步 7）；未开工程落步 1。会话内手动切步自由；手动落点**不持久化**，每次按事实重算（避免多一套要同步的状态）。

### 5.3 贴图工程自适应

步进器自动变 5 步：「成文」改名「贴图」（工作面 `CardsPanel`）；「配图」步隐藏（卡片自带图文，无逐图占位）；「导出」步隐藏（贴图产物即逐张卡片 PNG，无整文导出形态，打开卡片目录的入口已在贴图步内）。其余步骤与判定不变（审阅完成=`cards-review.md`）。

### 5.4 配图步（FigureChecklist）

- 行式清单：一行一个 fig-suggest 占位 = 序号 + 画面描述（直接可读，可改）+ 图注 + 状态徽标（待处理/已完成）+「处理 →」按钮；
- 顶部：n/m 进度条；「去正文查看」链接（切步 3 并滚动到对应占位）；
- 底部：已插图缩略图条（点击可替换——走 FigureDialog 对应管线）；
- 点「处理」：弹出现有 FigureDialog（三条管线不变），`onDone` 回写正文后清单自动刷新（事实重算）；
- 数据源：`parseFigSuggestions(articleMd)` shared 纯函数（占位行 → {序号, 描述, 图注}），可单测。

### 5.5 外部改动反应

沿用现有事件（`figure:rendered`、meta 热载、review.md 热载、文件 watcher），事件到达 → 重算推导。无新增事件通道。

### 5.6 错误处理

- LLM 调用失败：各步骤内 toast（现状平移）；
- 模型未配置：不拦切步；AI 步骤操作时报错，步 1 顶部常驻配置提示条（链到设置）；
- 导出/推送失败：ExportPanel 内展示（ExportDialog 现逻辑平移）；
- 覆盖确认：步 2「写入当前工程」遇非空正文保留 window.confirm。

## 9. 明确不做（YAGNI）

手动打卡；AI 一键配齐（批量生图）；排期/发布步；向导落点持久化；全屏沉浸模式；Skill 市场无关内容。
