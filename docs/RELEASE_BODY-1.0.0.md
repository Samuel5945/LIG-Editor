# 立格编辑器 1.0.0

> 覆盖 0.9.1 以来的全部更新：对话面板模型/思考双浮层重做、技能市场、长图导出、爆款拆解、大纲双向贯通。全量 744 项测试通过。

## 更新内容

- **对话面板模型/思考双浮层重做**：会话级模型选择——ZCode 风格分组菜单（供应商子菜单 + 模型列表），Ctrl+T 快捷呼出；思考强度四态档位（关/低/中/高）+ 渐变滑杆，商汤全档预置；「管理显示模型」可过滤菜单展示，支持全选/全不选
- **思考过程全程可见**：共享思考块组件接入对话、创作向导、审阅、排版优化、改稿五处；思考档位对 deepseek / glm / kimi 真正生效
- **技能市场 v1**：目录 / 搜索 / 预览 / 一键安装，在线刷新断网自动降级本地目录
- **长图导出双入口**：整文长图导出——离屏量高分段竖图 PNG（界面 + Agent 工具面双入口）；设计长图 + 设计贴图卡——AI 自写 HTML 排版直接出图
- **图文爆款拆解**：贴对标文案出六分区拆解报告（落 teardown.md），分析面板 / 编辑器选段 / 选题步拆对标三处入口，拆解骨架可一键转新文大纲
- **大纲双向贯通**：从成文反推大纲（outline.md 持久化 + AI 对话入口 + 向导自动带出）；大纲条目化 + 拖拽重排
- **体验审计收尾**：报告可发现、大纲同步权、胶囊信息、徽章如实、预览高度等一批细节缝合
- **修复**：「定位到原文」跳转真生效；审稿引用行定位容错；审阅骨架不再出桩报告；大纲步深链不再落空态；密钥明文降级界面如实警示
- **底座**：无头冒烟脚本钉进发版流程（产物六链路自动验证）；双协议流解析提取纯函数并钉测试
