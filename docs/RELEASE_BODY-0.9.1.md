# 立格编辑器 0.9.1

> 覆盖 0.9.0 以来的全部更新：封面口径重做、贴图卡片组大升级、Agent 工具面扩到 46 个、底座升级 Electron 44。

## 更新内容

- **封面全新口径**：公众号后台只认一张 2.35:1 主图，1:1 方图由它智能取景裁剪——六套版式各有一套排版，超采样出图更锐；另支持手写 HTML 直渲封面
- **贴图卡片组大升级**：缩略图点开大图预览（←/→ 翻卡）；整组渲染进度可中途停止，剩余可单张补渲；批量要点序号 / 深色底反白开关；复制卡片；生图一键真取消（UI 与 Agent 工具面贯通）
- **Agent 工具面 27 → 46**：每个写入口都有读出口；渲染结果回传成图，Agent 能自证排版；长口径改按需手册；外部 Agent 取消调用即中止在途生图
- **修复**：图片四项排版字段（形态/边框/外间距/图注）此前设置后并未真正生效，现已全链路贯通
- **稳定性**：界面异常不再整窗白屏（错误页可重载 / 复制详情）；对话等待有兜底超时；依赖瘦身安装更小
- **底座**：Electron 31 → 44，补齐两年来的 Chromium 安全更新
