# 日报八套排版主题（DESIGN DAILY #01–#74 反向归纳）

> 来源：ligdesign.win 设计日报全部 74 期（+51b 特刊）HTML 逐一提取视觉签名（底色 / 字体 / 主色频谱 / 栏目结构 / 卡片形态）后聚类而成。
> 用途：立格编辑器分类排版主题库的可落库预设。JSON 为 `ArticleTheme` 主题库口径（字号键是 `fontSize`，不是 meta 的 `bodyFontSize`），字段与枚举全部过 `sanitizeThemePatch` 校验（`categoryThemes.ts` / `themeFields.ts` 同一白名单）。
> 归纳日期：2026-10-03 · v2：随「页面纸底 pageBg + 报头横幅 h1Style banner/h1Bg」口径扩展升级，日报的双层表面与报头横幅已可直接落库（36 字段口径）。

## 落库三条路

1. **手工**：编辑器 🎛 全量排版面板逐项设置后「存为分类主题」（同名分类自动创建）。
2. **配置直灌**：把下方任一 JSON 按 `{ "主题名": { …ArticleTheme } }` 合并进 `settings/customThemes.json`，重启后主题库生效（自定义主题优先级高于内置 `CATEGORY_THEMES`）。
3. **AI 落库**：对话里让模型用 `save_theme_preset` 照 JSON 输出整套主题（name 即分类名）。
4. **反解导入**：直接把某期日报 HTML 喂给「从公众号文章导入排版」（themeParse）——body 纸底自动识别为页面纸底、通栏 H1 色条识别为报头横幅，再手工微调。

**口径注意**

- v2 起「页面纸底 + 正文卡」双层表面已还原：`pageBg` 是纸色外壳（导出时挂在卡片外一层，公众号剥最外层后纸底层仍存活），`bodyBg` 是正文卡。夜间两者都按公众号逻辑自动变深（深色底保持原样）。
- 深底主题（赛博霓虹、暗夜金红、孟菲斯深壳）在夜间模式保持原样不翻转（`resolveEditorTheme` 对深色基础底不深化的既有逻辑），白天看也是深卡，属预期。
- 加粗链：`strongColor` 不设时跟随 `accent`；标题字色同理。banner 横幅字色按 `h1Bg` 亮度自动对比，无需手调。
- 未写的键 = 跟随默认调性，不写满 36 项是有意留白。
